# SkyproWallet

Веб-приложение для учёта личных расходов: авторизация, добавление и удаление трат по
категориям, таблица расходов и наглядная аналитика за выбранный период.

**Демо:** https://drdic.github.io/skypro-wallet/

## Возможности

- **Регистрация и вход** — валидация полей на клиенте, понятные тексты ошибок,
  состояния загрузки и блокировка кнопки во время запроса.
- **Мои расходы** — таблица расходов с описанием, категорией, датой и суммой;
  добавление нового расхода через форму с выбором одной из шести категорий;
  удаление расхода прямо из строки таблицы.
- **Анализ расходов** — календарь периода с выбором диапазона дат и столбчатая
  диаграмма расходов по категориям. Расходы за период запрашиваются **с сервера**
  (`POST /transactions/period`), а не фильтруются на клиенте: если сервер начнёт
  отдавать данные постранично, аналитика останется корректной.
- **Выход из аккаунта** — подтверждение в модальном окне и очистка сессии.
- **Защита маршрутов** — приватные страницы недоступны без авторизации,
  авторизованный пользователь не попадает на страницы входа и регистрации.
- **Состояния экранов** — «загружаем», «пусто», «ошибка» с кнопкой «Повторить».
- **Адаптивная вёрстка** — интерфейс корректно перестраивается на экранах
  320, 375, 768, 1024 и 1200+ пикселей.
- **Страница 404** — в общем стиле проекта.

## Установка и запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Приложение откроется по адресу `http://localhost:5173/skypro-wallet/`.

Остальные команды:

```sh
npm run build    # сборка в dist/
npm run preview  # локальный просмотр собранной версии
npm run lint     # проверка и автоисправление кода
npm run format   # форматирование через Prettier
npm run deploy   # сборка и публикация на GitHub Pages
```

## Структура проекта

```text
src/
├── assets/       глобальные стили (theme, main, page) и SVG-иконки
├── components/   переиспользуемые компоненты (BaseHeader, ExpenseTable, CategoryChart…)
├── composables/  переиспользуемая логика (useTransactions, useExit, useAuthRedirect)
├── constants/    категории расходов и соответствие их значений в API
├── layout/       макеты страниц (AppLayout, AuthLayout)
├── router/       маршруты и навигационные guard'ы
├── services/     работа с API и сессией (api, auth, wallet, session)
├── utils/        форматирование сумм и дат, валидация форм
└── views/        страницы приложения
```

## Принципы кода

Проект следует принципам **KISS**, **DRY** и **YAGNI**:

- общая обработка ошибок API вынесена в `src/services/api.js`;
- повторяющаяся логика экранов вынесена в composables;
- страницы авторизации используют общий `AuthLayout`, стили страниц — общий `page.css`;
- в коде нет неиспользуемых переменных, закомментированных блоков и `console.log`.
