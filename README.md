# SkyproWallet (Vue)

Кошелёк для учёта расходов. Проект создан на **Vue 3 + Vite + Vue Router**.

**Текущий этап — Спринт 2 (hw-2): API и бизнес-логика.**
Спринт 1 (стартовый каркас и вёрстка) сдан, Спринт 2 готов: авторизация, работа
с расходами через API, валидация и обработка ошибок, календарь периода с прокруткой.

## Демо

**https://drdic.github.io/skypro-wallet/**

Собрано из ветки `hw-2` командой `npm run deploy` (Vite → `dist/` → ветка `gh-pages`).

## Что сделано в Спринте 1

### Каркас и инфраструктура

- Vue 3 (`<script setup>`), Vite, Vue Router.
- Алиас `@` → `src`, `base` для GitHub Pages (`/skypro-wallet/`).
- ESLint 9 (flat config) и Prettier, `.editorconfig`, `jsconfig.json`.
- Сборка и деплой через `gh-pages`, файл `public/404.html` для корректной работы
  SPA на GitHub Pages.

### Вёрстка экранов

- **Вход** — форма с полями логина и пароля, кнопка «Войти», ссылка на регистрацию.
- **Регистрация** — поля имени, эл. почты и пароля, кнопка «Зарегистрироваться»,
  ссылка на вход.
- **Мои расходы** — таблица расходов (описание, категория, дата, сумма) и форма
  «Новый расход» с выбором одной из шести категорий.
- **Анализ расходов** — блок «Период» с календарём и блок диаграммы по категориям
  (вёрстка без логики).
- **Выход** — экран подтверждения выхода.
- **404** — страница в общем стиле проекта.

### Общие компоненты

- `BaseLogo` — логотип и название проекта.
- `BaseHeader` — единая шапка с навигацией и кнопкой «Выйти».
- `BaseButton` — кнопка с вариантами оформления и состоянием `disabled`.
- `BaseInput` — поле ввода с состояниями обычное / фокус / заполненное.
- `BaseIcon` — вывод SVG-иконок через `currentColor`.
- `ExpenseTable` и `ExpenseRow` — таблица расходов и строка таблицы.
- `NewExpenseForm` — форма нового расхода с категориями-фишками.
- `PeriodCalendar` — календарь периода для страницы анализа.
- `CategoryChart` — столбчатая диаграмма по шести категориям.
- `ExitModal` — модальное окно подтверждения выхода.

## Что сделано в Спринте 2

### API и сервисы

- `src/services/auth.js` — вход и регистрация через реальный API, разбор ошибок сервера.
- `src/services/wallet.js` — чтение, создание и удаление расходов.
- `src/services/session.js` — хранение признака авторизации.
- Токен авторизации подставляется заголовком в каждый запрос к API.

### Логика экранов

- **Вход и регистрация** — валидация полей, состояние загрузки, текст ошибки под полем,
  `aria-invalid` для доступности.
- **Защита маршрутов** — неавторизованный пользователь уводится на вход, авторизованный
  не может открыть `/login` и `/register`.
- **Мои расходы** — данные с сервера, добавление и удаление расхода, состояния
  «загружаем / пусто / ошибка» с кнопкой «Повторить».
- **Анализ расходов** — календарь периода с прокруткой и выбором диапазона,
  диаграмма считается по фактическим данным за выбранный период.
- **Выход** — подтверждение в модальном окне и очистка сессии.

## Публикация на GitHub Pages

```sh
npm run deploy
```

`deploy` вызывает хук `predeploy` → `npm run build`, затем `gh-pages -d dist`
публикует содержимое `dist/` в ветку `gh-pages`. Исходники туда не попадают:
браузер не умеет исполнять `.vue`, поэтому на Pages уходит только собранная сборка.

`base: '/skypro-wallet/'` в [`vite.config.js`](vite.config.js:8) подставляет префикс
в ссылки на ассеты, а [`public/404.html`](public/404.html:6) содержит redirect-скрипт
`spa-github-pages` с `pathSegmentsToKeep = 1`, который восстанавливает глубокие ссылки
(`/skypro-wallet/login`, `/skypro-wallet/analysis`). Глубокие ссылки отдают HTTP 404 —
это штатное поведение GitHub Pages, страницу открывает сам redirect-скрипт в браузере.

После push в `gh-pages` обновление доезжает через CDN за несколько минут. Проверка
с обходом кэша: открыть `https://drdic.github.io/skypro-wallet/?cb=1` и сверить хеш
в `assets/index-*.js` с локальным `dist/`.

## Маршруты

| Путь         | Страница             |
| ------------ | -------------------- |
| `/`          | Мои расходы          |
| `/login`     | Вход                 |
| `/register`  | Регистрация          |
| `/analysis`  | Анализ расходов      |
| `/exit`      | Выход                |
| `*`          | Страница 404         |

## Структура проекта

- `src/layout/` — общий макет приложения (`AppLayout.vue`);
- `src/views/` — страницы приложения;
- `src/components/` — переиспользуемые компоненты;
- `src/router/` — маршруты приложения и защита приватных страниц;
- `src/services/` — запросы к API авторизации и расходов, работа с сессией;
- `src/constants/` — список категорий;
- `src/utils/` — вспомогательные функции (форматирование суммы и дат, валидация);
- `src/assets/` — глобальные стили и SVG-иконки;
- `public/` — favicon и `404.html` для GitHub Pages.
